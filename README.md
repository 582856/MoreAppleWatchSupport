# MoreAppleWatchSupport

让小米手机通过“设备互联”向 Apple Watch 转发更多应用的消息，并支持同步小米超级岛。

## 通知显示

由于手表应用限制，第三方应用的通知图标只能套用短信图标。

通知格式：

```text
应用名 | 通知标题 | 机型名
通知内容
```
